# R2 ZAI/GLM · 课堂任务迁移判断（Let's talk / 项目 / 表达）

> 席位：ZAI / GLM。只读审查，未改业务代码。
> 审查对象：沙漠 200 关（20 主题 × 10 关）vs PEP 三上（2024秋）/ 三下（2025春）课堂任务结构。
> 事实锚点：`source-notes.md` PEP 目录、`desert-map-level-questions.md` 全 200 关。
> 本席角度：不看宏观覆盖率（M3 席已做），只看**课堂任务级迁移**——孩子坐在 PEP 课堂上，面对 Let's talk 对话、Let's learn 词汇、Part C Project 时，哪些沙漠短语能直接用上，哪些用不上。

---

## 结论

**未达到。** 沙漠 200 关能撞上 PEP 课堂任务的只有约 55 关（27%），且全部停在"认出单词"层面，无法迁移到 Let's talk 对话轮次和 Project 产出。

核心矛盾不在覆盖率，在**任务形态错配**：

| PEP 课堂任务 | 需要孩子做什么 | 沙漠训练了什么 | 能否迁移 |
|---|---|---|---|
| Let's talk（对话） | 听对方说 → 用完整句回应 | 看中文 → 选英文短语 | 不能。沙漠没有 Q→A 轮次训练 |
| Let's learn（词汇） | 看图说单词 / 跟读 | 看中文 → 认英文短语 | 部分。能认，但沙漠教的是短语不是单词 |
| Part C Project | 用目标语言制作/展示 | 无对应训练 | 不能。沙漠无产出题型 |
| 单元驱动问题 | 用 How/What 句式回答 | 无 How/What 问法 | 不能。沙漠题干是"哪一句是在说「X」" |

一句话：PEP 课堂是**任务驱动**（每单元有驱动问题 + 对话 + 产出），沙漠是**指认驱动**（看中文选英文）。两套任务形态不在同一个层面，即使词汇重叠也无法迁移。

## 强贴合例子（5 条：这些短语孩子上课能用上）

### 1. L1-10 日常问候 → 三上 U1 Making friends + 三下 U1 Meeting new people · Let's talk

PEP 课堂场景：开学第一课，老师做 Let's talk 角色扮演——"Good morning! How are you?"，孩子需要回应。

沙漠已有：Good morning / How are you / Thank you / Goodbye / See you later / I'm sorry / Excuse me / You're welcome

迁移路径：老师说 "How are you?"，孩子脑子里闪出沙漠 L2 学过的这条短语 → 能认出这是在问"你好吗"。

**但断裂在**：PEP Let's talk 是轮次对话，老师问 "How are you?" 后期望孩子答 "I'm fine, thank you."。沙漠只教了问句 How are you，没教回应句 I'm fine / I'm good。孩子认得出问题，但接不住对话第二轮。要在 Let's talk 里"融会贯通"，至少需要把问候补成配对（问句 + 标准回应）。

### 2. L61-70 情绪表达 → 三下 U2 Expressing yourself · Part B "How do we express our feelings?"

PEP 课堂场景：Part B Let's learn 教 feeling words（happy/sad/angry/scared），Let's talk 做情绪表达对话——"How do you feel? / I'm happy."

沙漠已有：I'm happy / I'm sad / I'm angry / I'm scared / Be brave / Calm down / Don't cry / Cheer up

迁移路径：这是沙漠里**形态最接近 PEP 课堂产出**的一段。I'm happy / I'm sad 可以直接作为 Part B Let's talk 的回答句使用。Be brave / Calm down / Cheer up 还能用于安慰同伴的场景对话。

**但断裂在**：缺驱动问句。PEP Part B 的核心问题是 "How do we express our feelings?"，课堂会问 "How do you feel?"。沙漠没有这条问句，孩子学了一堆情绪答句但没有对应的问题输入。补一条 How do you feel 就能形成完整 Q→A。

### 3. L91-95 颜色 → 三上 U5 The colourful world · Part A "What colours do you see?"

PEP 课堂场景：Part A Let's learn 教颜色词，Let's talk 问 "What colours do you see?"，孩子回答 "I see red / yellow / blue."

沙漠已有：Red and blue / Yellow sun / Green grass / Black night / White snow

迁移路径：孩子上课学 red / yellow / green / black / white 时能认出——"这个我在沙漠 L91-95 见过"。

**但断裂在两个层面**：
- 形态不匹配：PEP 教单独颜色词（red），沙漠教颜色+名词搭配（Yellow sun / Green grass）。孩子要自己拆出 yellow / green。
- Part B 驱动问题 "How do colours help us?" 完全没覆盖。PEP 三上 U5 Part B 讨论颜色的功能（红绿灯、情绪色、警告色），沙漠 L91-100 全部是颜色认读，没有一条涉及"颜色有什么用"。L96-100 的形状（Round/Square/Triangle）更是 PEP U5 不教的内容。

### 4. L101-105 数字 → 三上 U6 Useful numbers · Part A "When do we use numbers?"

PEP 课堂场景：Part A Let's learn 教 one-ten 数字词，Let's talk 练习数数 / 报年龄 / 报电话号码。

沙漠已有：One to ten / Count to twenty / Plus one / Minus one / What time

迁移路径：数字词是最确定的迁移点。孩子上课学 one-two-three 时直接"我学过"。

**但断裂在**：PEP U6 驱动问题是 "When do we use numbers?"（什么时候用数字）和 "How useful are numbers?"（数字有什么用），核心是数的**应用场景**（年龄、时间、电话、日期）。沙漠 L101-105 教的是数数和加减（Plus one / Minus one），对应的是数学运算，不是 PEP 要的"应用场景"。L106-110 的时间表达（What time / Morning time / Today is / Tomorrow is）方向对了，但 PEP 三年级不教完整时间句式。

### 5. L121-130 动物宠物 → 三上 U3 Amazing animals · Part A "What pets do you know?"

PEP 课堂场景：Part A Let's learn 教宠物词（dog/cat/fish/bird/rabbit），Let's talk 问 "What pets do you know?"，孩子回答 "I know dogs / cats."

沙漠已有：Feed dog / Walk dog / Pet cat / Watch fish / Chase bird / Catch butterfly / Ride horse / Milk cow / Shear sheep / Collect eggs

迁移路径：动物名词（dog/cat/fish/bird）能从短语中提取出来，上课认词时"我学过"。

**但断裂在**：PEP 问 "What pets do you know?" 期望的回答是宠物**名词**（dogs/cats/fish），沙漠教的是"动作+动物"（Feed dog / Walk dog）。孩子要自己拆出 dog/cat/fish 才能回答课堂问题。而且 L126-130（Ride horse / Milk cow / Shear sheep / Collect eggs）是农场动作，不是 PEP U3 的 pets 或 wild animals 范畴。

## 断裂点（5 条：这些地方课堂迁移会断）

### 1. Let's talk 对话轮次完全缺失——认得出短语但接不住对话

PEP 每单元 Part A/B 都有 Let's talk，是对话练习（不是指认）。以三下 U1 为例：

> 老师: "How do we greet new people?"
> 孩子 A: "Good morning!"
> 孩子 B: "Hi! How are you?"
> 孩子 A: "I'm fine, thank you."

沙漠只教了 Good morning / How are you（单向短语），没有配对的回应句（I'm fine, thank you / Nice to meet you）。结果是：孩子认得出每个短语的意思，但在 Let's talk 对话里不知道该用哪一句回应对方。**认读 ≠ 对话**，这是最大的迁移断裂。

证据：沙漠 200 关中，问答配对（问句+回应句同时出现）= 0 组。所有短语都是孤立的单向表达。

### 2. Project 产出任务零覆盖——Part C 做不出东西

PEP 每单元 Part C 都有 Project（制作类任务）：

| PEP 单元 | Project | 需要的语言能力 | 沙漠覆盖 |
|---|---|---|---|
| 三上 U1 | Make a mind map of making friends | 交友关键词 + 分类 | 无 |
| 三上 U2 | Make a family tree | 家庭成员词 + 关系描述 | 无（L71-80 是动作不是成员词） |
| 三上 U3 | Make an animal picture book | 动物词 + 描述句 | 部分（L131-140 有动物+形容词） |
| 三上 U5 | Make a colour flip book | 颜色词 + 物品搭配 | 部分（L91-95 有颜色+名词） |
| 三下 U2 | Express feelings（Project 未列全） | 情绪词 + 表达句 | 部分（L61-70 有情绪句） |

大部分 Project 需要孩子**用目标语言产出内容**（写/画/说），沙漠的"中文→英文二选一"只能训练接收性识别，产出能力为零。即使词汇全部对齐，Project 仍然做不出来。

### 3. 单元驱动问题（How/What）完全不在沙漠题型里

PEP 2024 版每个单元都有驱动问题：

- 三上 U1: "How do we greet friends?"
- 三上 U3: "What pets do you know?"
- 三下 U2: "How do we express our feelings?"
- 三下 U3: "What tools help us learn?"

课堂讨论、小组问答都围绕驱动问题展开。沙漠题干是"哪一句是在说「X」？"——这是中文释义匹配，不是 PEP 的 How/What 问法。孩子即使背了 200 条短语，面对老师问 "What pets do you know?" 时也不知道该从记忆里调哪几条来回答。

证据：沙漠 200 关题干 100% 是"哪一句是在说「中文」？"格式，0 条使用 PEP 驱动问题问法。

### 4. 8 个主题（70 关）在 PEP 三上/三下课堂中根本不出现

从课堂任务角度看，这 70 关连"认出"的机会都没有：

| 主题 | 关数 | 沙漠内容 | PEP 三上/三下有无对应单元 |
|---|---|---|---|
| 洗漱卫生 L41-50 | 10 | Brush teeth / Wash face / Flush toilet… | 无 |
| 身体动作 L51-60 | 10 | Run fast / Jump high / Clap hands… | 无 |
| 天气季节 L111-120 | 10 | Sunny day / Rainy day / Hot summer… | 无（四上/四下才教天气） |
| 出行交通 L141-150 | 10 | By bus / Get on / Traffic light… | 无（四下才教交通） |
| 购物消费 L151-160 | 10 | How much / Too expensive / Keep change… | 无 |
| 音乐艺术 L171-180 | 10 | Sing song / Play piano / Clap rhythm… | 无 |
| 运动比赛 L181-190 | 10 | Kick ball / Run race / Score goal… | 无 |
| 职业梦想 L191-200 | 10 | Be a doctor / Be a singer / Be a writer… | 无（五上才教职业） |

这 70 关的英文不会在 PEP 三年级任何 Let's talk / Let's learn / Project 中出现。孩子上课不会有"我学过"的时刻。它们占沙漠首学 200 关的 35%，直接稀释迁移密度。

### 5. 强贴合主题内部仍有"形态断裂"——词不等于短语

即使是 9 个有 PEP 对应单元的主题，沙漠教的是**动作短语**（V+O），PEP 课堂要的是**名词词表 + 对话句**：

| 沙漠形态 | PEP 课堂需要 | 差距 |
|---|---|---|
| Feed dog / Walk dog / Pet cat（V+O 短语） | dog / cat / fish / bird（名词，Let's learn 词表） | 孩子要自己拆名词 |
| Red and blue / Yellow sun（颜色+名词） | red / blue / yellow（单独颜色词） | 孩子要自己拆颜色词 |
| Have breakfast / Have lunch（动作短语） | rice / bread / egg / milk（食物名词，U4 词表） | 完全不同的词汇集 |
| Read book / Write word（动作短语） | pen / pencil / ruler / bag（工具名词，U3 词表） | 完全不同的词汇集 |

PEP Let's learn 教的是**名词词表**（事物名称），沙漠教的是**动作短语**（做什么）。孩子上课翻开 Let's learn 看到的是 cat / dog / red / blue / pen / ruler，不是 feed dog / red and blue / read book。形态对不上，"我学过"的惊喜会被打断。

## 必改建议（从课堂任务迁移角度，4 步）

### 1. 补问答配对：让每个 PEP 单元的 Let's talk 能接住

最小改动：在每个强贴合主题里，把单向短语补成"问句 + 标准回应"配对。

示例（日常问候 L1-10 扩展）：
- 现有：Good morning / How are you / Thank you / I'm sorry
- 补配对：How are you → I'm fine, thank you / Thank you → You're welcome（已有）/ I'm sorry → That's OK / Good morning → Good morning

这样孩子在 PEP Let's talk 里遇到对话轮次时，不仅认得出问句，还能接住回应。

### 2. 加 PEP 驱动问题题型：从"中文释义"升级到"课堂问法"

最小改动：在每个强贴合主题的末尾 2-3 关，加 PEP 单元驱动问题题型。

示例（情绪表达 L61-70 末尾）：
- L69 题干改成："上课老师问 How do you feel? 你应该怎么回答？" → 正确答案 I'm happy（二选一干扰 I'm sad）
- L70 题干改成："上课老师问 How do we express our feelings? 选一个表达方式" → 正确答案 I'm happy

这样孩子上课听到 How/What 问法时，脑里有对应的"这道题我做过"锚点。

### 3. 按 PEP 单元 Part A/B 切组 + 用单元名做主题标签

最小改动：把 20 个生活主题重组成 12 个 PEP 单元组，主题名直接用 PEP 单元名。

示例重组：
- 「日常问候」+「家庭互动」→ **U1 Making friends + U2 Different families**（三上）
- 「动物宠物」+「动物园」→ **U3 Amazing animals**（三上）
- 「颜色形状」→ **U5 The colourful world**（三上），砍掉形状关
- 「数字时间」→ **U6 Useful numbers**（三上），砍掉时间句式关
- 「情绪表达」→ **U2 Expressing yourself**（三下）
- 「一日三餐」→ **U4 Healthy food**（三下），但要把进餐动作换成食物名词
- 「学校学习」→ **U3 Learning better**（三下），但要把学习动作换成工具名词

家长打开地图看到 PEP 单元名 = 信任建立。孩子做题知道在预习哪个单元 = 迁移有方向。

### 4. 每个强贴合单元末尾加 1 道 Project 迁移题

最小改动：每个 PEP 单元组最后 1 关不做事指认，改做"微型 Project 指引"。

示例（三上 U3 Amazing animals 组末关）：
- 题干："你的 animal picture book 第一页要画什么动物？" → 正确答案 See panda（二选一干扰 Watch monkey）
- 这样把 Project 任务的语言需求拆到关卡里，孩子做 Project 时有语言储备。

## 给汇总席的速判

1. **课堂任务迁移率 27%**（55/200 关能撞上 PEP Let's talk/learn），且全部停在"认出"层面，产出为零。
2. **最大断裂不是覆盖率，是任务形态**：沙漠做指认，PEP 要对话 + 产出。即使 200 关全部对齐 PEP 词汇，不做对话轮次和 Project 训练，仍然无法"融会贯通"。
3. **强贴合 5 个主题（问候/情绪/颜色/数字/动物）**的短语需要补问答配对 + 驱动问题题型才能迁移到 Let's talk。
4. **8 个偏离主题（70 关）应后移**到城堡/高年级地图，不在沙漠首学浪费迁移带宽。
5. **最短路径**：补问答配对 + 加驱动问题题型 + 按 PEP 单元切组 + 末关加 Project 迁移题。四步同时做，沙漠才能从"短语表"变成"课堂预学闭环"。
