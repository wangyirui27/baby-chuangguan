# 05 Grok · 沙漠 PEP 重做 · 产品 UX 验收（轻量）

> 席位：Grok 设计/前端 · 余额低，只做关键体验验收  
> 视角：家长 + 6–8 岁孩子  
> 目标：内容重做后，地图/题干/chip 必须让人一眼感到「这是人教 PEP 课堂抢跑」，不是生活短语表  
> 不做：视觉大改、地图美术重做、新玩法、改业务代码  
> 依据：`.hermes-work/pep-alignment/source-notes.md`、`docs/curriculum/desert-pep-classroom-transfer-review.md`、`script.js` 当前地图/答题展示事实  
> 红线：本文件只出 UX 验收；不改 `script.js` / `quiz.test.js` / `index.html` / `sw.js`

---

## 0. 一句话结论

**这轮内容重做若只换词句、不改「单元感」露出，家长仍当它是泛口语 App，孩子也难形成整课级“我早就学过”。**  
必须在**不换皮肤**的前提下，让现有地图词牌、关卡 pill、题干话术三处同时说出 PEP 单元。

---

## 1. 现状：孩子/家长各自看到什么

### 1.1 孩子（6–8）打开沙漠地图

| 触点 | 当前事实 | 孩子体感 |
|------|----------|----------|
| 地图名 | `沙漠奇境` / kicker `200 DESERT STOPS` | 冒险地图，不是课本 |
| 岛下词牌 | `level.title` 英文 + `zhTitle` 中文（如 Good morning / 早上好） | 只认「这一关的话」 |
| 关卡状态 | 序号浮在地标上 + 已完成/当前/锁 | 进度游戏感强 |
| 答题顶栏 pill | `第 N 关 · ${topicShort}` → 如「第 1 关 · 日常问候」 | 生活主题名，不是课本单元 |
| 题干 | `小朋友，视频里学到的单词，哪一个是「…」的意思？` | 测验口吻；短语却叫「单词」；任务=译意配对，不是课堂应答 |

结果：孩子可能记住单句，但**不会把一串关卡记成「Making friends 那一课」**。上课听到老师整单元推进时，惊喜是零星火花，不是整课连击。

### 1.2 家长扫一眼（信任决策 3 秒）

| 家长会找的信号 | 当前有没有 | 判断 |
|----------------|------------|------|
| 人教/PEP/三上三下 | 无 | 不买账「同步教材」 |
| 课本单元名（Making friends 等） | 无；只有「日常问候/洗漱卫生/购物消费…」 | 像市面生活口语包 |
| 能对照课本目录核对 | 无 | 无法建立「预习」叙事 |
| 题型像课堂（问答/对话/项目） | 无；全是中译英 2 选 1 | 像认读小测，不像上课 |

**家长信任感不来自沙漠美术，而来自「我能拿着课本目录对上号」。** 当前对不上。

### 1.3 产品叙事错位（必须写进验收）

- 地图切换文案已暗示沙漠是「6–8 · 句型对话冲刺」，但内容骨架是 20 个生活主题短语表。  
- 海岛=单词启蒙、沙漠=课堂表达——这条分工对；沙漠若不显 PEP 单元，整条年龄进阶故事断掉。

## 2. PEP 单元感应如何展示（不重做视觉）

原则：**复用现有 HUD 槽位**（顶栏 pill、岛下词牌、可选一行小字），不新开复杂面板、不加游戏化皮肤。

### 2.1 信息层级（孩子先懂玩，家长一眼信）

```
L0 地图身份（已有）     沙漠奇境
L1 课本航段（缺 → 必补）  三上 · Unit 1 交朋友 Making friends
L2 关内角色（已有改口径）  第 12 关 · 会问会答
L3 本关表达（已有）       Good morning / 早上好
L4 课堂钩子（题干改）     老师问 How do we greet friends? 你怎么说？
```

L1 是本轮**最小必补**。没有 L1，后面词句再准，地图仍像短语摊。

### 2.2 推荐露出位置（按实现成本从低到高）

| 优先级 | 位置 | 现在 | 重做后最小文案 | 谁受益 |
|--------|------|------|----------------|--------|
| P0 | 答题顶栏 `.level-pill` | `第 N 关 · 日常问候` | `第 N 关 · 三上U1 交朋友` | 孩子连续关有单元感；家长旁观也看到 |
| P0 | 题干话术 | 「单词…意思」 | 见 §3，禁「单词」；课堂情境优先 | 孩子迁移 |
| P0 | 数据/topic 字段 | 生活主题名 | 必须能解析出 `3A-U1` + 中文短名 + 英文单元名 | 全链路 |
| P1 | 岛下词牌副行 | 仅 zhTitle | 主行仍英文表达；副行可 `早上好 · 交朋友`（单元短名 ≤4 字） | 地图浏览时单元连续感 |
| P1 | 地图顶 brand 次行/kicker | `200 DESERT STOPS` | 可改为进度向：`PEP 三上三下 · 12 单元`（非营销长句） | 家长 3 秒信任 |
| P2 | 单元边界关（每单元第 1 关） | 无差别 | 仅文案：pill 带「新单元」或 topic 含 Part A 起步，不需新 UI 组件 | 分段记忆 |
| 不做 | 新地图章节页、证书墙、课本封面拟态、大量标签色 | — | 本轮禁止视觉大改 | — |

### 2.3 单元命名（孩子能读 + 家长能对目录）

| 用途 | 格式 | 例 | 禁 |
|------|------|----|----|
| 孩子短名（pill/chip ≤ 8 汉字逻辑宽度） | 动词/名词短语 | 交朋友 / 不一样的家 / 神奇动物 | 整句英文单元名塞满 pill |
| 家长对账名 | `三上 U1 · Making friends` | 可在长文案、家长报告、单元首关说明 | 只写英文或只写内部 id |
| 内部 id | `3A-U1` / `3B-U4` | 数据字段 | 暴露给孩子 |

**12 单元孩子短名建议（定稿可微调用词，但必须稳定）：**

| id | 短名 | 家长对账 |
|----|------|----------|
| 3A-U1 | 交朋友 | 三上 U1 Making friends |
| 3A-U2 | 不一样的家 | 三上 U2 Different families |
| 3A-U3 | 神奇动物 | 三上 U3 Amazing animals |
| 3A-U4 | 身边的植物 | 三上 U4 Plants around us |
| 3A-U5 | 彩色世界 | 三上 U5 The colourful world |
| 3A-U6 | 有用的数字 | 三上 U6 Useful numbers |
| 3B-U1 | 认识新朋友 | 三下 U1 Meeting new people |
| 3B-U2 | 表达自己 | 三下 U2 Expressing yourself |
| 3B-U3 | 学得更好 | 三下 U3 Learning better |
| 3B-U4 | 健康食物 | 三下 U4 Healthy food |
| 3B-U5 | 旧玩具 | 三下 U5 Old toys |
| 3B-U6 | 生活中的数字 | 三下 U6 Numbers in life |

地图主线 **只允许这 12 段**。洗漱/交通/购物/职业等不得再占沙漠主线 topic（可进更后地图，本轮 UX 验收不接受它们继续稀释单元密度）。

### 2.4 关内三层在 UI 上怎么「感觉到」——仍用同一答题壳

不新增题型引擎也能做出分层感：靠 **pill 后缀 + 题干句式** 区分。

| 层 | 目标 | pill 后缀示例 | 题干气质 |
|----|------|---------------|----------|
| 预学 | 先认核心表达 | `· 先学会` | 「刚才学的那句，哪一句是在说「…」？」 |
| 课堂问法 | 接住 How/What/Who | `· 会问答` | 「老师问：How do we greet friends? 你怎么说？」 |
| 项目迁移 | 对应 Part C 微任务 | `· 小任务` | 「做朋友思维图，这一格贴哪一句？」 |

同一 2 选 1 大按钮；**分层靠文案，不靠新玩法。** 这是本轮最短路径。
