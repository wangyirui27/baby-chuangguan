## 路径

1. **冷启动**  
   - 启动非纯白闪很久；出现登录（必登）  
   - 显示名桌面图标为「嗨洛塔」

2. **登录**  
   - 发短信 → 填码 → 进「我的」/地图  
   - 杀进程重进仍保持登录（session）

3. **英语前 10**  
   - 进沙漠/海洋主地图 → 第 1–10 关可点  
   - 每关：视频能播、题能答、单词音效能出  
   - 通关进度本地/服务端至少一端可见

4. **数学小桌**  
   - 进数学地图 → 打开一关（如 118 compose）  
   - 题面无 `+/=/?` 硬符号；拖珠/分合可完成  
   - 关卡语音与题面一致

5. **跳关弹窗（数学）**  
   - 打开跳关：每关有「已通关」或「未通关」  
   - 当前关：`当前 · 已通关/未通关`  
   - 段标题：`已通 n/m`

6. **静音 / 返回**  
   - FAB 静音有效；系统返回/手势不白屏崩溃

7. **（可选）IAP**  
   - 仅当 ASC 已建 `baby_island_map_vip_001`  
   - 拉起系统购买框；取消不崩溃；恢复购买无报错

8. **更新桥（可选）**  
   - 若人为抬高 `app-release.json` 远端版本，弹窗文案含嗨洛塔、能打开商店搜
