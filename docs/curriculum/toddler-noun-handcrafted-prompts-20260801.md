# 3-5岁生活名词精修稿 v1

目标：非母语零基础儿童看完视频后，回到现实生活里看到同一个东西，能自然脱口而出英文名词。

硬规则：
- 海岛只是地图入口，视频不教海岛主题词。
- 每关只教一个名词，画面先于声音讲清含义。
- 画面像真实生活里的小记忆，不像词卡、课堂或模板演示。
- 共享画风可以统一，但每关的生活触发点必须单独设计。
- 1-10关名词锁定不改，但文生视频提示词也按本稿逐条精修。
