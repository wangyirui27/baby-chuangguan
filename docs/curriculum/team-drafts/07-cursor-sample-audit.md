## 事实锚点（已核对源码，非猜测）

| 锚点 | 源码事实 |
|---|---|
| 海岛可见关数 | `levels.length === 200`（`quiz.test.js` 断言） |
| 沙漠可见关数 | `desertLevels.length === 200`；`quiz.test.js` 称 *fixed 200 phrase curriculum* |
| 题干函数 | `questionPromptText(level)` → `` `小朋友，视频里学到的单词，哪一个是${level.zhTitle}的意思？` ``（无地图分支） |
| 题型一实际选项 | `correctWord` + `distractors[0]`；`distractors = level.options.filter((_, i) => i !== level.correct)`，即 **options 数组顺序下第一个非正确答案** |
| UI 题干 HTML | 同样硬编码「单词」：`小朋友，视频里学到的单词，…「${level.zhTitle}」…` |

**干扰项读取规则（本报告统一）**：`distractor = level.options` 中第一个 `index !== level.correct` 的项。

## 3. 专项：desert 短语 vs「单词」产品文案

### 证据链

1. **课程定位**：`quiz.test.js` → `desert map uses the fixed 200 phrase curriculum`；前 10 关均为多词短语（如 `Good morning`、`How are you`）。
2. **题干生成**：`questionPromptText` 无 `mapWorld` / 短语分支，一律输出「…学到的**单词**…」。
3. **答题页 UI**：`renderDetail` 内 `questionHtml` 再次硬编码「单词」（与朗读同源问题）。
4. **测试缺口**：`quiz.test.js` 对 `questionPromptText` 的断言只覆盖海岛名词样例（如奶奶）；**未断言沙漠应说「短语」**，故回归锁不住该产品问题。

### 判定

- **问题成立（产品文案）**：沙漠 200 关短语课程，在题干朗读与屏幕文案上被统一称为「单词」。
- **本抽样**：沙漠 10/10 全部复现。
- **非本抽样范围但同源**：凡走 `questionPromptText(level)` / 同 HTML 模板的沙漠关，预期全量复现（因函数无分支）。

### 建议方向（仅记录，本席不改代码）

- `questionPromptText`（及 `questionHtml`）按地图或内容形态分支：海岛「单词」/ 沙漠「短语」（或中性「哪一个是…的意思」）。
- 补 `quiz.test.js`：对 `desertLevels` 抽样断言题干不含误导「单词」，或显式期望「短语」。
- 若已有沙漠 question 音频 manifest，文案改动需同步语音资产（本席未验音频文件内容）。
