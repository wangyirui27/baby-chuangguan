# Codex 海岛地图 1-200 关内容草案

## 读取口径

- 数据源：`script.js` 导出的 `levels`，取 `levels.slice(0, 200)`；当前 `levels.length=200`。
- `desertLevels.length=200`，本稿不纳入沙漠地图内容。
- 正式题型一取 `correctWord + 第一个非正确 option` 后再随机打乱；本表“实际2选1干扰项”记录进入题局的干扰词，不表示固定屏幕位置。
- `questionPromptText(level)` 示例：小朋友，视频里学到的单词，哪一个是妈妈的意思？
- 本表“孩子看到的题目中文文案”按 `renderDetail` 里的视觉题干 `questionHtml` 去标签后记录。
