## 0. 真实产品一句话（写截图前先钉死）

**嗨洛塔 = 3–8 岁孩子在故事地图里闯关：先看短片，再做一道能点的题，推进下一关。**  
英语主线：魔法海岛（词）+ 沙漠奇境（句）。  
数学主线：数学小桌（数感操作）+ 31 条数学 story 短片。  
不是课件库，不是题库 App，不是“全科神器”。

代码事实（不可被营销改写）：

| 能力 | 代码事实 | 营销可用口径 |
|------|----------|--------------|
| 英语关卡机制 | `renderDetail`：先视频 → 再 2 选 1 辨认（词/句） | 看完动画才出题；点对解锁下一关 |
| 英语“跟读” | guidance 文案写“听清并跟读”，**主路径不是语音评分** | 可说“听清楚、跟画面开口”；**不能说“智能纠音/口语测评”** |
| 数学机制 | 地图内联操作题 + story 短片 + coach/自适应 + Mine 简报 | 摸着数、凑着算；家长能看见练得怎样 |
| 免费门槛 | `FREE_LEVEL_COUNT = 10`，每图前 10 关 | 打开就能玩，不用先买 |
| 付费 | 地图 VIP 买断（`baby_island_map_vip_001`），11 关起 | 先体验再决定；别在前 3 图讲价格表 |
| 双线入口 | `MAP_WORLDS`：ocean/desert zone=english；math zone=math | 同一座学园，两条线，不是两个 App 堆叠 |
| 适龄 | ocean 3–5 / desert 6–8 / math 3–5（世界选择器 meta） | 按年龄进对的地图，不是一锅炖 |
| 设备 | iPhone+iPad 都支持竖/横；产品与官网优先 **iPad 横屏** | iPad 是主画布；iPhone 是同叙事便携版 |
| 未上线 | 大语文研发中；埃及/西部/铁路/城堡 coming soon；math58/math912 占位 | **前 3 图与副标题一律不提** |

## 1) 转化漏斗与截图排序

### 1.1 家长 5 秒决策漏斗（App Store 上半屏）

家长不是在“比较功能列表”，是在连问 4 个是/否：

1. **这是给我家这个年龄的吗？**（3–8）  
2. **孩子打开后到底干什么？**（不是“教育类”四个字）  
3. **是在学，还是在空刷动画？**（有没有“做完才过关”）  
4. **我要不要全程盯着？**（负担感）

前 3 张图必须按这个顺序回答，**一张只解决一个决策**。第 4 张以后才扩世界、家长报告、双设备。

### 1.2 推荐截图序列（商店前 3 + 可选后排）

| 序 | 漏斗位 | 画面内容（内容层，非画风） | 5 秒内家长应得到的结论 |
|----|--------|----------------------------|------------------------|
| **1** | 品类+年龄+主承诺 | **冒险地图全景**（优先魔法海岛或世界选择器：英语/数学都可见，但视觉焦点只有一个“当前可玩世界”） | “这是 3–8 岁故事闯关启蒙，不是题库/不是动画片合集” |
| **2** | 核心玩法证明 | **剧情短片播放中**（真实关卡，如 Mom / Good morning；画面有“认真看完，问题马上出现”一类状态更佳） | “孩子先被故事吸住——下一课就是下一集” |
| **3** | 学习发生证明 | **答题瞬间**（英语 2 大选项 / 或数学小桌大触控选择）。**前 3 里二选一即可，不要英数各占半屏** | “不是白看：要选对/做对才能过关” |
| 4（可选） | 双线不堆砌 | **世界选择器**：海岛/沙漠/数学小桌并排，带适龄标签（3–5 / 6–8），coming soon 弱化或裁掉 | “一个 App，按年龄选线；不是功能堆砌” |
| 5（可选） | 家长安心 | **Mine 家长总览或数学简报**（进度、建议继续哪张图、正确率） | “我能看见练了什么，不用全程监工” |
| 6（可选） | 深度/更新 | 多地图缩略或 story 长廊 | “内容在长，不是十关就结束”——**禁止列未上线世界当卖点** |

官网 `website/index.html` 已用 **地图 → 视频 → 小测** 三连，与本漏斗一致；商店应延续，不要另起“功能墙”叙事。

### 1.3 前 3 张的硬排序理由

- **图1 必须是地图/世界，不能是答题特写**：没有“我在哪”的上下文，选项图会像普通闪卡 App。  
- **图2 必须是视频/故事，不能是家长报告**：家长先信“孩子愿意打开”，再信“有数据”。  
- **图3 必须出现“孩子动手”**：关掉“只是动画片”的怀疑；这是下载转化的关键帧。  
- **英数不要在前 3 张里对半分屏**：双线在图 1 用入口暗示即可，图 4 再展开；前 3 抢的是“懂了吗”，不是“全不全”。

## 2) 每张图唯一决策信息

规则：**一张图只让家长记住一句；副标题 caption 也只服务这一句。**

### 图 1 · 我是谁

- **唯一决策信息**：3–8 岁 · 故事地图闯关启蒙  
- **画面只服务**：岛/地图进度感 + 品牌名“嗨洛塔”可读  
- **caption 方向**：`故事地图里闯关启蒙` / `下一座岛，就是下一课`  
- **禁止同屏塞**：价格、VIP、400 关数字墙、大语文、七个世界徽章、排行榜

### 图 2 · 孩子怎么玩

- **唯一决策信息**：先看短片，再进入关卡（被吸引，不是被逼上课）  
- **画面只服务**：全屏/大窗剧情视频 + 关卡名（英文词/句清晰）  
- **caption 方向**：`看完动画才出题` / `孩子追的是剧情`  
- **禁止**：功能列表、多学科 icon 条、对比竞品

### 图 3 · 是不是真在学

- **唯一决策信息**：过关要辨认/操作，不是滑完就过  
- **画面只服务**：一道题、两个（或少量）巨大选项；可见“选/提交”状态  
- **caption 方向**：`选对了，才开下一关` / `听懂了，点得出来`  
- **英数选择**：  
  - 默认主转化线用 **英语 2 选 1**（与官网三连、免费前 10 转化路径一致）  
  - 若投放人群偏“幼小数感”，图 3 可换成 **数学小桌一题**，但图 1/2 叙事仍统一为“故事闯关”，不要突然变成“数学教具 App”

### 图 4 · 双线怎么理解（不进前 3 也要写清）

- **唯一决策信息**：同一套闯关习惯，按年龄选英语线或数学线  
- **caption 方向**：`3–5 海岛词 · 6–8 沙漠句 · 数学小桌数感`  
- **禁止**：把 coming soon 世界画成已上线；禁止“英语+数学+语文+科学”

### 图 5 · 家长角色

- **唯一决策信息**：进度可回看，建议继续哪张图；陪伴≠监工  
- **caption 方向**：`打开就知道练到哪`  
- **禁止**：夸大 AI 诊断、保证提分、学校成绩承诺

## 3) 适合 / 不适合的文案语气

### 3.1 主标题 / 副标题建议（短、有欲望）

**主标题（App 名旁展示名已是「嗨洛塔」）商店推广标题候选：**

1. `下一集动画，就是下一课`（与官网一致，最强）  
2. `半小时屏幕，换成能过关的启蒙`  
3. `孩子追剧情，顺手学会了`

**副标题候选（≤30 汉字量级思维，最终以 ASC 字数裁）：**

1. `3–8岁故事闯关 · 英语数学在地图里发生`  
2. `看短片、做一题、开下一关`  
3. `先被吸引，才会自己点下一座岛`

### 3.2 适合的语气

| 维度 | 做法 | 例句 |
|------|------|------|
| 具体行为 | 写孩子手上在干什么 | 看完再选；点对开下一关 |
| 家长痛点 | 点到“屏幕空虚/催学疲劳”，不贩卖焦虑 | 半小时之后，要留下一点东西 |
| 产品边界 | 承认启蒙、兴趣、习惯 | 学前启蒙闯关，不替代学校 |
| 双线 | 一条习惯，两种内容 | 同一张地图习惯，英语说得出、数学摸得着 |
| 欲望 | 短、画面感、可想象今晚 | 今晚从第 1 座岛开始 |

### 3.3 不适合的语气（禁词与禁结构）

| 禁止 | 原因（对真实代码） |
|------|-------------------|
| 神器 / 全能 / 一次搞定幼小衔接 | 过度承诺；大语文未上线 |
| 保证提分 / 考级 / 同步教材全覆盖 | 条款与产品定位都不支持 |
| AI 私教 / 智能纠音 / 外教同款 | 英语主路径是 2 选 1；数学 AI coach 是辅助且可回退本地 |
| 400+ 关 / 7 大世界堆在副标题 | 功能堆砌；coming soon 会构成误导风险 |
| “没有课件也没有题库”用在审核敏感位 | 品牌态度可以，但商店需同时诚实：有明确关卡与题目 |
| 对标“线上一对一只要 99”类攻击性对比 | 可留在 App 内 paywall；商店截图不适合开战 |
| Emoji 墙、感叹号连环 | 与品牌沉浸叙事冲突，显廉价 |

### 3.4 官网文案审计（给 Kimi 的对齐注意）

可沿用：

- `孩子的下一集动画，就是他的下一课`  
- `把半小时屏幕，换成一关能说出口的冒险`  
- `认真看完，问题马上出现`（App 内真实 video-hint）  
- `截图没有修过` 的诚实姿态  

需降调或改写后再上商店：

- `语音跟读嵌在剧情里` → 改为 `听清画面里的英语，再选出来`（除非产品上线真实跟读评分）  
- `430 多支原创关卡动画` → 商店用可核验口径：`海岛/沙漠关卡动画 + 数学 story 短片`；具体支数以包内/OSS 可证为准，不写虚高  
- `3 条学习主线`（hero-proof）→ 商店只写 **已上线：英语 + 数学**；语文保持研发中，不进前 3

## 4) 对 MVP 学习闭环的判断

对照：输入目标 → 练习 → 反馈 → 复习 → 进度沉淀。

| 环节 | 英语 | 数学 | 商店能否当主卖点 |
|------|------|------|------------------|
| 输入目标 | 地图当前关、连续解锁、世界推荐 | 地图任务点 + story 路点 | 能（图1） |
| 练习 | 视频 + 2 选 1 | story 短片 + 桌面操作题 | 能（图2–3） |
| 反馈 | 对错音效、庆祝、重来不惩罚 | coach 横幅、本地音效、自适应升降 | 能轻提，不写“AI 名师” |
| 复习 | 错题本 + 已通关可重进；**无独立阶段复习关** | 后期关有阶段复习题型；简报建议 | **弱项：勿主打“科学复习系统”** |
| 进度沉淀 | 本地+云同步、英语区家长总览、词库并集 | mathAttempts、Mine 数学简报 | 能（图5），作安心项不是钩子 |

### 4.1 结论（直说）

1. **MVP 闭环在“当次闯关”上是成立的**：孩子知道下一关在哪、做完有反馈、进度会留下。这足够支撑商店主叙事。  
2. **闭环短板在“复习召回”**：英语没有独立复习模式；错题本偏记录。营销若承诺“螺旋复习/自适应全科路径”，超过现状。  
3. **双线不是伪需求**：代码里 zone、进度、家长总览已拆英/数；但 **双线是扩展，不是第一钩子**。第一钩子永远是“故事里闯关”。  
4. **免费前 10 关是真实转化漏斗**（`lessonOverrides` 固定前 10）：商店与截图应服务“今晚就能玩通前几关”，而不是服务“看完功能表再下载”。  
5. **付费叙事后置**：VIP 矩阵对比适合 App 内 11 关墙；不进前 3 截图。  
6. **设备**：iPad 横屏是体验主场；iPhone 必须能讲同一故事，但不要假装竖屏闪卡是主设计。

### 4.2 双线如何避免“功能堆砌”

正确结构（心智模型）：

```
嗨洛塔
 └─ 一种习惯：看故事 → 做一题 → 开下一关
      ├─ 英语线：海岛词（3–5）→ 沙漠句（6–8）
      └─ 数学线：小桌数感（3–5）〔更高龄数学地图未开〕
```

错误结构（禁止）：

```
功能：动画 / 单词 / 句型 / 数学 / AI / 语音 / 排行榜 / 7 世界 / 语文…
```

执行规则：

- 副标题最多 **一个习惯 + 两个学科名**。  
- 截图 caption 不出现第三个学科。  
- 世界数量用“地图在长大”，不用枚举未上线地名。  
- 年龄分流写在图 4，不写在图 1 的多标签角标风暴里。
