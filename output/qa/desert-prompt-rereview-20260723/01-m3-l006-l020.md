## 2. 跨类系统性发现（audit by class, not by site）

按"发现一个 copy-paste 污染时必须审计同类"的铁律，把 L006-L020 的逐关观察归纳成几个系统性观察：

### 2.1 模板复读问题已系统性修复 ✅
r1 的"5-beat 模板：A 念 target → B 念 target → A 念 target → B 说 Yes/Me too → 两人合念 target"在 r2 prompt 里已**全部消失**。15 关的 dialogue 段都是自然 Q-A / 邀请-接受 / 关心-回应 / 介绍-问候 结构。这是 r2 重做最关键的胜利。

### 2.2 项目活动标签（C 类）的处理 ✅
L010 / L013 / L014 / L015 / L016 / L017 这 6 个 title 是 C 类项目活动标签，r2 prompt 的处理方式一致：
- dialogue 段完全没有念标题
- spokenDialogue 是自然儿童英语
- 但 answerOption.correct 仍是标题本身
- curriculumVerdict 都是 REGENERATE 或 DELETE

**问题**：answerOption 的正确选项是项目标签（"Share with friends" / "kind words" / "help a friend" / "say hello first" / "be a good friend"）— 这不是 prompt 修复能解决的，是 curriculum 设计决策（这关到底教什么、quiz 怎么出）。

### 2.3 末拍"两人合说"的口号化风险 ⚠️
12/15 关的 12-15s 末拍是 "We are friends!" / "We are good friends!" / "We are happy!" / "We did it!" 这类**单元收束口号**。在 6 岁真实对话里，最后一拍往往是挥手告别（"Bye!" / "See you!"）或动作（一起走开），不是关系总结。L015 / L017 的末拍更明显是 slogan（"Friends help!" / "We are good friends!"）。

不是阻断红线，但作为 prompt 质量瑕疵，**建议**把这几关的 12-15s 末拍改成动作收束或告别，而不是关系宣言。

### 2.4 家庭系列的视觉区分度不对称 ⚠️
L018 (mum) / L019 (dad) / L020 (grandma) 三关的视觉锚点不对称：
- L019 mustShow 显式写"爸爸有男性外貌特征"
- L020 mustShow 显式写"奶奶有灰发特征"
- **L018 mustShow 只写"A 指着身旁的妈妈介绍；B 礼貌问候"，没写妈妈的外貌锚点**

家庭三胞胎里 mum 是最弱的。L018 的 distractor 在 post-gen silent-forced-choice 时，可能 mum 和 grandma 都满足视觉（都是女性长者）— 这是个具体风险点。

### 2.5 L013 / L014 的 DELETE 候选与 prompt 质量分离
L013 / L014 的 curriculumVerdict=DELETE，但**r2 prompt 本身的质量是 15 关里最精致的**（mustShow 5-7 条，含 state-change 描述）。这说明 prompt 工程和 curriculum 设计是两件事：r2 prompt 已经达到 prompt-level 顶级，但项目标签作为答案选项在 curriculum-level 仍然不该保留。

### 2.6 Negative Prompt 一致性 ✅
15 关的 Negative Prompt 完全一致（同样的 21 个 ban 词顺序）。这是好的，不是 copy-paste 污染 — 因为负面词本来就是公共清单，必须一致。**没有发现 Negative Prompt 被某一关私自改坏的情况**。

### 2.7 L006 vs L007 的 spokenCount 差异说明 ⚠️
L006 spokenCount=4（"My name is Tom." 在 dialogue 里出现 4 次，因为 Lily 也说了同句型）
L007 spokenCount=8（"What's your name?" 是问题，孩子会重复询问，符合 Q-A 节奏）
这数字差异合理。**spokenCount 是 dialogue-quoted-lines 计数，不是 whole-prompt title chant**，r2 checker 已修对。
